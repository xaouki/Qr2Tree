# Qr2Tree 🌳

A modern, browser-based QR generator with a magical tree-inspired visual experience.

## Features
- QR code generation from links or text
- Live customization of size and color
- PNG download
- Copy source content
- Responsive mobile-first interface
- No backend and no data storage
- GitHub Pages ready

## Run
Open `index.html` in a browser, or enable GitHub Pages for the repository.
